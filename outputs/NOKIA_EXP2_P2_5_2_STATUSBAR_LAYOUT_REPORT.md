# Nokia Experience 2 — P2.5.2 Pixel-accurate Status Bar Layout

Status: **PASS**

## Причина дефекта P2.5.1

В P2.5.1 правая шкала рисовалась левее батарейной иконки:

```text
indicator: batteryX - 11dp
mark:      batteryX + 1dp
```

При этом `batteryX` также участвовал в расчёте зоны уведомлений. В результате вертикальная шкала попадала в область конверта и визуально распадалась на два отдельных элемента.

## Новая структура

StatusGlyph разделён на независимые зоны Canvas с явными слотами:

| Группа | Element | X | Y | Size |
|---|---|---:|---:|---:|
| Левая | Индикатор сети | `signalX` | `1dp` | `9.98×24dp` |
| Левая | Сеть | centered on indicator axis | `26dp` | `35×38px` |
| Центр | Время/дата/оператор | `signalX+19dp` | existing | existing |
| Центр/правая | Уведомления/Wi-Fi | calculated before right zone | existing | existing |
| Правая | Индикатор батареи | `batteryX+1dp` | `1dp` | `10.46×24dp` |
| Правая | Батарея | centered on indicator axis | `25dp` | `40×46px` |

`batteryX = width - 15dp`; правая группа заканчивается примерно на `width - 3dp`, то есть графика не обрезается. Иконка батареи и индикатор имеют одинаковую X-зону и разные Y-слоты. Между ними оставлен вертикальный зазор 1dp.

Левая группа также использует одну X-зону и вертикальное размещение: индикатор сверху, значок сети непосредственно под ним. Центральная зона не пересекается с левой группой, а правая шкала начинается после области уведомлений.

## Фактический экран и масштаб

Устройство Nokia B:

- physical size: `1080×1920`;
- physical density: `480 dpi`;
- active override density: `420 dpi`;
- effective density: `2.625`.

При этом effective density размеры составляют примерно:

- network indicator: `26.25×63 px`;
- network mark: `26.25×31.5 px`;
- battery indicator: `28.88×63 px`;
- battery mark: `28.88×39.38 px`.

Масштабирование равномерное: SVG не растягиваются отдельно по X/Y и не изменяются по path data.
