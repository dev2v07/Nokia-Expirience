# Nokia Experience — modern Android launcher MVP

Build date: 30 September 2026. APK: `outputs/NokiaExperience-debug.apk`, **4,770,433 bytes**, SHA-256 `BFB14321E7F1FC7B5C02C77B8B767876EB0E52DD652D7B1FCFABCC46F7F961A6`. This replaces the earlier S60 Canvas Home/Menu with an Android-native, touch-first launcher. N95 is still the default visual profile; 5530 selects a separate color/panel treatment, while **both deliberately use the same Nokia icon set**. No Symbian ROM, RPKG, root or custom lock screen is in the APK.

## Architecture

- `LauncherActivity.java`: single HOME/DEFAULT Activity with an **opaque** window, transparent **native** Android status bar, WallpaperManager static-wallpaper ImageView, gesture-discriminated Home, horizontal paged App Drawer, independent Home workspace, 3-slot dock, settings, SAF picker, widget host, Android lifecycle and startup/audio.
- `HomeWorkspaceModel.java`: SharedPreferences-backed 4×3 Home pages, cell positions, swapping, Home folders and their contents. It does not alter the independent dock or Android package registry.
- `MenuModel.java` + `MenuOrganizer.java`: PackageManager discovery, persistent app order, folders/assignment/hidden list. Installs/removals update via dynamic package receiver and onResume.
- `IconStore.java` + `AssetRepository.java`: same 15 manually sourced Nokia-style PNG assets for both profiles, Android package icons as fallback, per-component document URI override saved in SharedPreferences; reset-to-default. Manual assets are **provisional**, not verified original N95 MIF/AIF.
- `AndroidActionResolver.java`: checked native Intents/component launch, no Samsung package hardcoding. Chrome dock default is resolved by discovered app label; if absent, browser Intent fallback.
- `WidgetPreviewPicker.java` + `AppWidgetHost` / `AppWidgetManager`: the existing visual chooser and actual host views remain intact. A touch-aware frame around each real host view now enters edit mode on long press, cancels the provider's pending tap, shows move/resize/remove handles, persists widget order and dimensions, and calls `updateAppWidgetOptions()` when a provider advertises resizing. The Android 8 A5 exposes only a text-based Settings handler for public `ACTION_APPWIDGET_PICK`, not Samsung Experience's private visual chooser. A system picker fallback remains if provider metadata is unavailable; no fake previews are generated.
- `DeviceStateAdapters.java`: actual battery and network state. Small battery/signal graphics in Launcher content are derived from the supplied Nokia screenshot (`assets/reference/`); **Android's real status bar remains enabled and retains its Android-native icons**.
- `NokiaSounds.java`: original RM-320 multimedia-menu select WAV through SoundPool for in-app taps, respects silent/vibrate and UI-sound preference.
- `StartupView.java`: retained 20 decoded Startup.mbm frames; one-frame-at-a-time memory use, uniform scaling, skip after 250 ms, fade to Home. The user-supplied Connecting People MP3 is played via MediaPlayer for **both** visual profiles, stops on skip/finish/pause and can be disabled.

The old `NokiaSceneRenderer.java` and `TouchNavigationController.java` were removed from the live UI. `S60CanvasMapper.java` remains only for proportional startup-frame rendering; the 240×320 N95 frame is not the Android UI resolution.

## Implemented behavior

| Area | Current result |
|---|---|
| Home / drawer | No visible Menu button or device/profile title on Home. Upward motion opens **only** App Drawer and cancels pending empty-area long press; stationary long press opens context actions. Each horizontal drawer page contains 3×5 or 3×6 icon+label cells, with no search/vertical scroll/page sound. `HorizontalScrollView` follows the finger and snaps on release. Cells have no individual card. The launcher package is excluded from PackageManager results, while one dedicated synthetic `Nokia Experience · Настройки` entry opens launcher Settings; Android Settings is a separate item. |
| App editing | Long press and move starts drag; long press and release opens edit actions. Drawer apps can be added to independent Home workspace or explicitly assigned to the dock. Custom/reset icon, folders, reorder, hide/restore, system uninstall and app details remain. Home apps can be moved among snapped cells, combined into folders, removed from Home and persisted across process restart. |
| Home shortcuts | Three configurable slots, defaults `Телефон` / `Chrome` / `Камера` on a Russian-language device. Long press a slot to choose app; any drawer app can be assigned to a dock position. |
| Wallpaper | The Activity window and Home surface are opaque. `WallpaperManager.getDrawable()` supplies the actual static Android Home wallpaper for the background ImageView; no Samsung Home surface is exposed. A one-time runtime storage permission explanation/request appears if Android 8 denies reading the current wallpaper. Until granted, the built-in static wallpaper is used as a safe fallback. Drawer uses a cached small blurred snapshot, or the same unblurred wallpaper if blur is off. Wallpaper-change broadcast refreshes the image. Picker uses Android ACTION_OPEN_DOCUMENT and attempts to set the selected image as system Home wallpaper. Live wallpapers cannot be mirrored as live content into an opaque third-party Activity through this static API. |
| Widgets | Existing visual provider-metadata picker remains unchanged. AppWidgetHost stores IDs and restores real views. Long press now shows edit bounds and controls; move reorders Home widgets, remove deletes host ID, and dragging the resize handle updates persisted size and AppWidget options when the provider supports it. Multiple widgets occupy a scrollable upper region, leaving a separate touchable Home grid. |
| Visual profiles | N95/5530 selected at runtime; both share Nokia icon mapping. The independent Red, Blue, Black, Orange and Cyan presets (or profile default) recolor panels/dock/title/selection. Profile, color, panel transparency, drawer dim and blur use separate SharedPreferences keys. Home has no N95/5530 title. |
| Status area | Native Android status/navigation bars and system lock screen preserved. Status bar background is transparent, with wallpaper beneath native Android icons. No extra full-width status strip or second clock. Small screenshot-derived Nokia signal and battery segments live in Home content. Real BatteryManager/BATTERY_CHANGED percent and charging state control 7 segments (charge-cycle animation; low-level blink); PhoneStateListener signal/service callbacks control signal segments and clear them when service is lost. Wi-Fi/Bluetooth/notifications remain Android-native. |
| Sounds | 67 original non-silent RM-320 sound candidates bundled and catalogued in `NOKIA_SOUND_CATALOG.md`. Only original multimedia-menu select WAV is the Launcher UI default. Startup stays the user-supplied MP3. Other apps' ringtone/message/notification/alarm/camera sounds are not silently overridden. |

## Settings and persistence

Nokia Experience settings are opened by the dedicated App Drawer icon, stationary long press on empty Home, or drawer options. They expose profile, **independent theme color preset**, grid rows, wallpaper, blur strength, dim percentage, **panel transparency (0–90%)**, three dock shortcuts, visual widget picker, startup animation/sound, UI sounds and menu-layout reset. Changing color does not reset dim, blur or transparency. Panel transparency does **not** make the Activity window translucent; drawer title remains unboxed. SharedPreferences persists these plus menu state, Home workspace cells/folders, custom icon SAF URIs, widget IDs/order/sizes. A prior `opacity_menu` value remains a compatibility fallback. Android system Settings is a separate drawer item.

Installing the APK does not automatically select it as default Home.

## Known limitations / required acceptance checks

1. Android does not expose a public API for a third-party launcher to replace just the battery or cellular glyphs **inside the native status bar**. Small Nokia glyphs therefore live on transparent Home content below it; Android status icons remain intact.
2. Samsung Experience's visual widget picker is not an exported public `ACTION_APPWIDGET_PICK` handler on this A5; the only public handler is `com.android.settings/.AppWidgetPickActivity`, which displayed a textual list. The new chooser renders only real `AppWidgetProviderInfo.previewImage` metadata (or an explicitly identified provider icon when absent). Binding, configure and restoration still depend on providers/permissions. Test add, restart, remove and provider uninstall on the unlocked A5.
3. Manual Nokia icons are not proven N95 MIF/AIF rasterizations. Missing apps fall back to their Android icons. Both profiles intentionally share this icon source.
4. The four white status sprite shapes are cropped/alpha-derived from the supplied reference screenshot, while their Home placement and dp scaling remain design tokens, not historically measured Nokia hardware pixels. No new Symbian emulation was added.
5. Launcher cannot alter other apps' notification channels, alarms, camera shutter sounds or system ringtone by packaging files. RNG is Symbian-specific and remains unplayed. Distribution rights for Nokia artwork/audio require separate review.
6. Live wallpaper or OEM restrictions may prevent WallpaperManager from returning the user's static drawable. The opaque Activity then displays Android's built-in static wallpaper when available, or its black base as the last-resort safe fallback; it never reveals Samsung Home. Android 8 may require the user to grant `READ_EXTERNAL_STORAGE` before the actual static wallpaper is available. The system lock screen is untouched.
7. Still requiring hands-on acceptance: direct finger drag from Drawer to Home drop target, Home cell-to-cell/folder drag, widget move/resize handle and provider response, theme color/opacity/dim/blur combinations, both profiles, signal changes/SIM loss, charge animation and low-battery blink, startup skip/audio and silent mode, orientation, package installs/removals and low-memory return. The A5 was charging at ~84–86%, so the low-battery path could not be exercised. No low-battery or charging sound was added; other apps' system sounds remain untouched.
