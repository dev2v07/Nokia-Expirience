# Edit Mode

Samsung: `OBSERVED` на устройстве A через ADB long-press. UI hierarchy содержит `Добавить страницу`, `Удалить`, `Обои`, `Темы`, `Виджеты`, `Настройки экрана`, а скриншот показывает preview рабочих столов и нижнюю панель действий. Синтетический сценарий не объявляется физическим touch acceptance.

Nokia Exp 2: Exp2-only edit overlay реализован поверх Home без изменения JSON. Доступны превью существующих страниц, выбор страницы, обои, виджеты, настройки и временный пустой экран. Пустая страница не сохраняется отдельно до появления содержимого.

Статус Nokia: `REPLICATED`; ручной вход долгим нажатием требует отдельной физической проверки: `NOT_VERIFIED`.

Парное расхождение: Samsung имеет действие «Темы», Nokia overlay пока показывает «Обои», «Виджеты», «Настройки», а также добавление/удаление временного экрана. Это зафиксировано как MISMATCH, без немедленного изменения кода.
