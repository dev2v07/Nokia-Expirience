# Nokia N95 8GB (RM-320): фактически декодированные визуальные ресурсы

Состояние на 30 сентября 2026 г. Исследовалась только рабочая копия `data/drives/z/rm-320/`; исходный `.7z` и `SYM.rom` не изменялись. Нумерация image ID в этом документе и CSV — **с нуля**, как в таблицах контейнеров. PNG находятся в [ASSET_PREVIEW](ASSET_PREVIEW/README.md), а полный реестр — в [MBM_IMAGE_INDEX.csv](ASSET_PREVIEW/MBM_IMAGE_INDEX.csv). Он содержит отдельную строку для каждого из 341 MBM-изображения.

## Инструменты и проверка

- В среде есть Python 3.12 и Pillow 12.3. Специализированные `bmconv`, `mifconv`, `rcomp`, декодер `.skn` и EKA2L1 не обнаружены. 7-Zip не читает MIF/MBM как архивы.
- Локальный анализатор в `work/n95_decode/decode_mbm.py` читает заголовок Symbian MBM, таблицу image ID и режимы RLE `0/1/3/4`; используются [поля оригинального Symbian `SEpocBitmapHeader`](https://github.com/SymbianRevive/symbian-headers/blob/main/bitmap.h) и [исходный код `bmconv`](https://github.com/loociano/symbian-build-tools). Выход записывается только в `work/` и `outputs/`.
- Для всех 341 записей проверены допустимость смещений, размеры заголовков и достаточность декомпрессированного потока. Ошибок декодирования не было. Это подтверждает чтение контейнера и пикселей, но **не** доказывает назначение каждого UI-элемента.
- RGB565/24-битные и серые/монохромные PNG пригодны для прямого изучения. Для `8-bit, color=1` реконструкция S60 Color256 в превью **предварительная**: точный порядок индексов и зависимые от темы цвета не подтверждены. Таких изображений 103; в 82 используются индексы `226–255`, явно требующие проверки палитры. Их нельзя брать как эталон цветов.
- Связь цветного изображения с соседней серой/чёрно-белой маской определяется только по соседству ID и одинаковому размеру: найдено 117 **предполагаемых** пар. PNG вида `_with_mask_...` — исследовательская композиция, а не доказанная схема наложения в S60.

## Дескрипторы тем `.skn`

Дескрипторы существуют в `private/10207114/import/<UID>/` и совпадают по UID с каталогами `resource/skins/<UID>/`: `101f84b9/Series60Skin.skn`, `2000a62a/NSeries07_01.skn`, `2000a62b/NSeries07_02.skn`, `2000a62d/NSeries07_04.skn`, `2000a62e/NSeries07_05.skn`. Сам факт присутствия тем в Z-диске не определяет активную тему пользователя: в дампе нет текущего состояния C-диска.
