# Nokia N95 RM-320 — визуальный каталог

Все PNG ниже получены из рабочей копии дампа. Имя `<container>_<ID>.png` содержит нулевой индекс изображения в MBM. Файлы `_with_mask_` — только исследовательские композиции с **предполагаемой** соседней маской. Для 8-bit Color256 оттенки в превью предварительные; точные цвета схемы не подтверждены.

## Индексы

- [MBM_IMAGE_INDEX.csv](MBM_IMAGE_INDEX.csv) — 341 фактически декодированное изображение: исходный путь, ID, размер, цветовая глубина, компрессия, маска, назначение и ссылка на PNG.
- [MIF_SLOT_INDEX.csv](MIF_SLOT_INDEX.csv) — 2124 слота версии 2 в приоритетных MIF; это **инвентаризация**, не визуальный декод.
- [MIF_FILE_INDEX.csv](MIF_FILE_INDEX.csv) — все 333 MIF-контейнера дампа, включая 93 `_aif.mif`.
